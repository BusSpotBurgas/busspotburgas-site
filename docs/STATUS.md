## 2. Етап 7 – какво има

- `src/components/Legal.tsx` – пълни „Правила за ползване“ и „Политика за поверителност“ (BG/EN)
- `src/lib/profile-actions.ts` – „Изтегли моите данни“ връща всичко за спотъра
- `supabase/migrations/0010_hardening.sql` – затягане по Security Advisor (приложено в Supabase)
- `src/components/Analytics.tsx` – Cloudflare Web Analytics (код в Netlify: `NEXT_PUBLIC_CF_BEACON_TOKEN`)
- `.github/workflows/`:
  - `ping.yml` – всеки ден пинг на Supabase
  - `backup.yml` – всяка неделя архив на базата (Actions → Artifacts, пази се 90 дни)
  - `timetables.yml` – всеки понеделник обновява разписанията (`scripts/import-livetransport.mjs`)
  - `gitleaks.yml` – при всяко качване проверка за изтекли ключове (`.gitleaks.toml`)
- Тайни в GitHub (Settings → Secrets → Actions): `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SECRET_KEY`, `SUPABASE_DB_URL`

## 3. Недовършено и известни неща

- „Сподели в story“ и „Изтегли моите данни“ не са пробвани с истински профил/снимка.
- Архивът е само на базата (снимките в Supabase Storage не се архивират).
- „Leaked password protection“ в Supabase е само за платения план.
- Официалният GTFS от Бургасбус не е получен; разписанията идват от livetransport.eu.
- Бележките над линиите са само на български.
